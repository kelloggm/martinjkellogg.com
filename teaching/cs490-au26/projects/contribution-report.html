Individual Contribution Report Due Friday, 13 November 2026, 11:59PM AoE.

This is an individual assignment: every student submits their own report, even though the work you are reporting on is your team’s.

At this point in the semester, your team has been working for about seven weeks and has given three demos. The purpose of this assignment is to make each student’s individual technical contribution to the project visible to the course staff, at a point in the semester when there is still time to do something about it if the answer is “not much yet.”

We are looking for evidence, not assertions. “I helped with the backend” tells us nothing; a link to a merged pull request does.

The Task

Submit a short report (roughly one page, and no more than two) containing the following four sections.

1. Code you wrote

List the pull requests that you authored in your team’s repository. For each one, give:

  • the PR number and a link to it,
  • a one-sentence description of what it does, and
  • whether it has been merged.

If you have pair programmed, say so, and make sure the commits in question use Git’s co-author feature so that the history reflects who actually wrote the code.

2. Code you reviewed

List the pull requests that you reviewed (that were authored by someone else), with links. For each, give a one-sentence description of what you asked for or what you caught. If you approved a PR without comments, say that—it is a legitimate outcome, but we want to know.

3. Your tasks from the work breakdown

List the tasks from your team’s revised project plan that were assigned to you, and give the current status of each: done, in progress, not started, or dropped. If a task was dropped or reassigned, say why in a sentence.

4. Reflection

In no more than 300 words, answer these questions:

  • What is the most technically difficult thing you have done on this project so far?
  • What is the biggest risk to your remaining tasks being finished by December 9, and what are you doing about it?

A note on what this is (and isn’t)

This report is not a competition with your teammates, and there is no target number of pull requests. Teams divide work differently, and some valuable work (design, debugging someone else’s problem, wrestling with deployment) leaves a smaller trace in the commit history than it deserves. If that describes your situation, use the reflection section to explain what you actually did, and point at whatever evidence exists—issues, review comments, meeting notes.

What we are looking for is evidence that every student is engaged in the technical work of the project. If your report shows that you are not, we would much rather find that out in November than in December.

Grading

This assignment is worth 3% of your project grade, as one of the project’s individually-graded components. See the project overview for how the project grade fits together.

Satisfactory:

  • All four sections are present.
  • Every claim in sections 1-3 is supported by a link to the team’s GitHub repository, or by an explanation of why no link exists.
  • Task statuses in section 3 correspond to the work breakdown in the team’s revised project plan.
  • The reflection answers both questions, and identifies a specific risk rather than a generic one.
  • The evidence in the report shows that you are making technical contributions to your team’s project.

Meets minimum requirements:

  • All four sections are present.
  • Sections 1-3 are accurate, but may be incomplete or thin on evidence.
  • The evidence in the report shows that you are making technical contributions to your team’s project.

A preview of the final reflection

The individual reflection that you will submit at the end of the semester has this same four-section structure, covering the whole project instead of just the first seven weeks, with a much longer version of section 4. Keeping your own records as you go—which pull requests were yours, which ones you reviewed—will make both assignments easier.

Submission

Submit as a PDF to Canvas (section 001, section 003, section HM1), under the assignment “Individual Contribution Report.”
